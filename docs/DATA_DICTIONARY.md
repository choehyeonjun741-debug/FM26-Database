# 데이터 사전

| 필드 | 의미 |
|---|---|
| player_id | 선수 고유 ID |
| current_club_id | 현재 뛰는 구단 ID |
| contract_club_id | 선수 계약을 보유한 구단 ID |
| contract_id | 현재 계약 ID |
| loan_id | 현재 임대 계약 ID |
| transfer_id | 관련 이적 ID |
| type | 이적/임대 형태 |
| option_fee | 선택적 완전이적료 |
| obligation_fee | 의무적 완전이적료 |
| wage_amount | 급여 금액 |
| wage_period | 급여 지급 주기 |
